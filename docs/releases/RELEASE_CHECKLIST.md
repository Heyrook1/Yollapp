# Release Checklist

## Product
- [ ] Acceptance criteria verified
- [ ] Required analytics verified
- [ ] User-facing copy reviewed

## Engineering
- [ ] Typecheck passes
- [ ] Lint passes
- [ ] Automated tests pass
- [ ] Database migrations reviewed
- [ ] Rollback plan documented

## Security and Privacy
- [ ] Authentication and authorization reviewed
- [ ] Secrets and environment configuration reviewed
- [ ] Privacy and consent behavior reviewed
- [ ] Abuse prevention and rate limits reviewed

## Experience
- [ ] Loading, empty, error, offline, and success states verified
- [ ] Accessibility checks completed
- [ ] Phone, tablet, and web layouts verified where applicable

## Operations
- [ ] Monitoring and crash reporting verified
- [ ] Alerts are actionable
- [ ] Release owner assigned
- [ ] Known risks accepted and recorded

## Verdict
- [ ] APPROVE
- [ ] APPROVE WITH CHANGES
- [ ] REJECT
